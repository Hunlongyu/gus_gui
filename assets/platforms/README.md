# Platform badges

These assets are embedded in the executable and loaded without network access.

- `gitgud.png`: [GitGud's website favicon](https://gitgud.io/gitgud/about.gitgud.io/-/raw/master/favicon.png), retrieved 2026-11-11. Used to identify GitGud; no affiliation is implied.
- `codeberg.svg`, `gitee.svg`, `bitbucket.svg`, `gitcode.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), retrieved 2026-11-11.
- `azuredevops.svg`: [Simple Icons 10.0.0](https://github.com/simple-icons/simple-icons/blob/10.0.0/icons/azuredevops.svg).
- `gitea.svg`, `forgejo.svg`, `sourcehut.svg`, `sourceforge.svg`, `launchpad.svg`, `alibabacloud.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), retrieved 2026-11-11. Codeup uses the Alibaba Cloud brand mark.
- `coding.svg`: symbol extracted from [CODING's official logo](https://help-assets.codehub.cn/enterprise/guanwang/coding-logo.svg), retrieved 2026-11-11. The wordmark is omitted, the canvas is square, and the fill uses `currentColor`. Used to identify CODING; no affiliation is implied. This brand asset is not covered by the Simple Icons license.

The Simple Icons assets use CC0-1.0; see `LICENSE-simple-icons.md`. Brand names and marks belong to their respective owners.

Provider detection uses known public Git hosts, including CODING team subdomains and Codeup regional organization domains. Other self-hosted instances and SSH aliases keep the generic host badge; their product cannot be determined from an arbitrary hostname without contacting the server.
